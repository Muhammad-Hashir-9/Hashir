Overview

Purpose and scope

A PIC18F452 assembly system that interprets two-sensor doorway sequences, tracks room occupancy, controls a lighting output, and reports state changes on a 16 × 2 LCD.

Engineering work

What the work covered

  • Implemented a continuously polled assembly state machine that distinguishes entry, exit, and incomplete door-crossing sequences from two infrared sensor inputs.
  • Stored the live occupancy count in a PIC18 register, kept the room-light output active while occupants remained, and cleared it when the room became empty.
  • Drove an 8-bit LCD through PORTD with RC0–RC2 control lines, including command, character, single-digit count, and Timer0-based delay routines.
  • Validated empty-room, first-entry, additional-entry, leaving, and pass-through behavior in a Proteus circuit using the PIC18F452, IR sensor models, LCD, and LED load.
  • Preserved a successful MPASM/MPLINK 4.48 build with HEX and COF images; the linker map records 744 of 33,048 program addresses used.
  • Documented the breadboard prototype, pin mapping, build steps, simulation recovery steps, known design limits, original report, and group contributors.
