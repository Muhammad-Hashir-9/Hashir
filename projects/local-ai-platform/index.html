Overview

Purpose and scope

A persistent multi-user local AI stack combining Ollama, Open WebUI, and Stable Diffusion with GPU-aware orchestration, trusted-LAN access, automated startup, and recovery controls.

Engineering work

What the work covered

  • Deployed local language, vision, document, coding, tool-calling, and image-generation workflows through Open WebUI, Ollama, and AUTOMATIC1111 on Ubuntu under WSL 2.
  • Integrated Stable Diffusion as a callable tool so a vision-language model can recognize an image request, invoke the local generation API, and return the result in the same conversation.
  • Used systemd and Docker restart policies for service supervision, persistent Open WebUI storage, and deliberate version pinning for repeatable upgrades and rollbacks.
  • Implemented independent pre-login and post-login Windows Task Scheduler paths so the WSL-hosted stack can recover across boot and login conditions.
  • Built a five-minute VRAM idle watchdog plus a Docker-private auto-reload proxy that unloads Stable Diffusion when idle and reloads it before the next generation request.
  • Scoped Open WebUI and image-generation access to trusted LAN clients while keeping the raw Ollama API internal, with documented health checks, backup procedures, and recovery steps.
  • Diagnosed and recovered an Open WebUI loading-screen failure through container, API, log, version, persistence, and browser-cache checks while retaining a rollback container and database backup.
