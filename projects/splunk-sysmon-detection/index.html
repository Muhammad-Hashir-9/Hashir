Overview

Purpose and scope

An end-to-end home-lab detection pipeline that simulates an endpoint compromise, captures Sysmon telemetry, correlates process lineage in Splunk, and fires a validated real-time alert.

Engineering work

What the work covered

  • Built an isolated internal network with a Kali Linux attack node and Windows 10 endpoint running Splunk Enterprise and Microsoft Sysmon.
  • Configured the Splunk Add-on for Sysmon so process-creation XML was parsed into useful fields including parent process, executable, command line, and ProcessGuid.
  • Ran a controlled reverse-shell simulation covering payload creation, local HTTP delivery, execution, session handling, and basic post-exploitation reconnaissance.
  • Correlated the malicious parent-child process chain with SPL and ProcessGuid, then independently designed a high-severity alert for a disguised PDF executable spawning cmd.exe or PowerShell.
  • Repeated the simulation to verify alert behavior and cross-checked the result through Splunk, netstat, and Windows Task Manager instead of relying on one source of evidence.
  • The initial environment and attack exercise followed a guided home-lab tutorial; the SPL detection, alert configuration, and repeatable validation were implemented as an independent extension.
